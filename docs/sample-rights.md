# 同梱サンプル曲の権利根拠

`src/soramimic_video/static/sample/` の同梱サンプル曲(生成元は
`examples/gen_samples.py`)は、**詞・曲ともに日本国内でパブリックドメイン(PD)**
の童謡・唱歌(および同じ基準を満たす英語圏の古謡・賛美歌)だけで構成する。
曲を足すときは必ずこの表に1行足し、作詞者・作曲者の**没年**を明記すること。

## 判定基準

日本の著作権保護期間は 2018年12月30日(TPP11整備法の施行日)に「没後50年」から
「没後70年」へ延長された。ただし**施行日時点ですでに切れていた著作権は復活しない**
(著作権法改正附則)。したがって国内著作物については次のどちらかを満たせばPD。

- **1967年以前に没**した著作者の著作物 … 旧法の没後50年が2018年12月29日までに
  満了しており、延長の対象外。
- **1955年以前に没**した著作者の著作物 … 現行の没後70年でも満了。
- **無名・変名(作者不詳の文部省唱歌など)** … 公表後70年で満了。

保護期間はいずれも**没年(公表年)の翌年1月1日から起算**する。戦時加算は
連合国民の著作物にのみ適用されるので、国内の唱歌・童謡には効かない。

新規に追加する曲は、余裕を見て**「作詞者・作曲者ともに1955年以前没、または作者不詳」**
を満たすものだけを採る。疑わしい曲は採用しない。

### 外国曲の場合

外国の著作物にも上と同じ基準(作詞者・作曲者ともに1955年以前没、または作者不詳)を
適用する。連合国民の著作物には**戦時加算**(最大3794日≒10年5か月)が乗るので、
その分を足してもなお満了していることを確かめる。実際には**19世紀以前に没した
著作者・作者不詳の伝承曲**だけを採るので、戦時加算を足しても余裕をもって満了する。
編曲にも別途著作権が生じうるため、旋律は**19世紀までに出版された公知の楽譜**の
系統に基づいて手打ちし、20世紀の編曲版(Excell版など)は参照しない。

## メロディと歌詞データについて

- メロディは公知の楽譜(Wikipediaの楽譜、うたごえサークルおけら、mu-tech等)を
  複数ソースで突き合わせて手打ちしたもの。**既存の市販打ち込みデータは含まない**。
  編曲そのものに著作権が生じうるので、既存MIDIの流用はしないこと。
- 歌詞テキストは1番のみ。表記は現代仮名遣いに寄せてある(原詞は歴史的仮名遣い)。
- 歌唱データは**1音符=1モーラ**に正規化してある(合成エンジンが1音符に複数モーラを
  載せられないため)。楽譜のメリスマは「け」→「け・え」のように母音のモーラを
  足して表す。促音・長音が独立した音符を持たない箇所は
  「桃太郎さん」→「ももたろさん」のように歌唱どおり詰める。
- 英語詞の曲は歌詞をカタカナ読みにして持たせる。英語の1音節は複数モーラに
  なることが多いので、その音符を16分・8分に分割して割り付ける
  (「star」→ ス・タ・ー、「amazing」→ ア|メ・イ|ジ・ン・グ)。
  「ファ」「トゥ」のような1モーラ2文字の表記は使わず「フ・ア」「ツ」に開く
  (1音符=1モーラの検証に合わせるため)。
- 伴奏(ch1)は `gen_samples.py` の `chords`(小節ごとのコード名)から機械的に
  作った、拍頭にベースとブロックコードを置くだけのもの。**既存の編曲は写さない**。
  たとえば「紅葉」の現行教科書版は中野義見の二部合唱編曲で保護期間内なので、
  低音部を写してはいけない(同梱データは斉唱の主旋律＋自前のコード付けだけ)。
