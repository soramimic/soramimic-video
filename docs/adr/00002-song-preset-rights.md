# ADR 00002: 曲プリセットの権利条件

- Status: accepted
- Date: 2026-08-12

## Decision

曲プリセットは、楽曲、歌詞、編曲・打込み MIDI の各層について、利用と再配布の条件を
個別に確認します。楽曲本体の利用が許可されていても、第三者が作成した MIDI や歌詞を
再配布できるとは限りません。

素材は次の基準で扱います。

1. 楽曲・歌詞が public domain で、MIDI も自作または再配布可能なものは公開 repository へ
   同梱できます。根拠と MIDI の作成方法を `docs/sample-rights.md` に記録します。
2. open license 等により楽曲・歌詞・MIDI を再配布できるものは、必要な作者、出典、license、
   変更内容、表示を記録したうえで同梱できます。
3. サービス内利用だけが許可され、素材の再配布が許可されないものは、素材 file を client へ
   配布する preset として公開しません。
4. いずれかの権利または出所が確認できないものは preset 化せず、利用者自身の upload に限ります。

外部素材には最低限、曲名、楽曲・歌詞・MIDI それぞれの作者と source URL、license または
許諾条件、取得日、改変内容、必要な credit、再配布可否を記録します。

## Consequences

- 公開 repository へ同梱する素材は、第三者が根拠と必要な表示を確認できる状態にします。
- 素材をアプリで処理できることと、その素材を再配布できることを別々に判断します。
- 必要な attribution、license notice、権利者指定の文言は省略または改変しません。
