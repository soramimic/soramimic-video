# ADR 00001: 完成動画の再生・保存・共有

- Status: accepted

## Decision

完成動画は、端末が file sharing に対応する場合、同じ MP4 file を再生と共有に利用します。

- 完成画面には、枠なしのアイコンと文字で「保存」メニューと「共有」を表示します。
  履歴には「保存」メニューを表示し、独立した共有ボタンは設けません。共有非対応の環境でも保存できます。
- 保存メニュー内を「動画」「歌唱データ」に分け、動画、MusicXML、歌詞入りMIDI、XF MIDI、
  伴奏なし歌声WAVから利用できる形式を選べます。歌唱データの独立した欄は表示しません。
- iPhone・iPadの動画保存は、写真への保存を選べる共有シートを開きます。共有非対応時や
  共有が拒否された場合の保存は直接ダウンロードを使います。
- 共有シートでの保存方法を事前に案内し、「次回から表示しない」を選ぶと同じブラウザーでは
  省略します。Android・PCの動画保存は直接ダウンロードします。
- 完成直後は再生と共有に使うファイルを事前に準備し、履歴ではiPhone・iPadの動画保存を選んでから準備します。
- 共有は利用者の明示的な操作から開始します。準備後も操作権限が有効なら、そのまま共有画面を開きます。
  操作権限が失効した場合は準備したファイルを保持し、完成画面では「共有を開く」、履歴では「保存を続ける」で再タップを案内します。
- 共有の準備または再生に失敗した場合は、直接再生・直接 download へ fallback します。
- 画面を離れた場合は、準備中の取得と一時 URL を解放します。
- 共有の取消は error として表示しません。それ以外の共有 error では直接 download を案内します。

この方針は、対応端末で動画 file 付き共有を提供しつつ、共有 API を利用できない環境にも
保存手段を残すための最終仕様です。
